## 一、第一份文档（通用微服务方案）：完全否决

### 1.1 结论：永久拒绝，不予执行

| 提议 | 裁决 | 理由 |
|------|------|------|
| Java/Spring Boot重写 | ❌ 永久禁止 | 我们是TypeScript全栈，重写等于自杀 |
| 微服务拆分10个服务 | ❌ 12个月内禁止 | 0收入阶段，微服务是自杀行为 |
| Nacos服务注册发现 | ❌ 不需要 | 单体内不需要服务发现 |
| Kafka消息队列 | ❌ 12个月内禁止 | pg_notify+Redis队列足够 |
| Kubernetes集群 | ❌ 24个月内禁止 | 一台VPS就够了，不要K8s |
| Istio服务网格 | ❌ 犯罪级过度设计 | 10个用户不需要服务网格 |
| 分布式事务Seata | ❌ 不需要 | 单数据库ACID事务强一致 |
| 多数据库拆分 | ❌ 禁止 | 单PostgreSQL实例足够 |

### 1.2 为什么这是一份"简历驱动开发"的方案

这份文档是**标准的互联网大厂中间件简历模板**，不是创业公司方案：
- 它假设你有50人技术团队、10000 QPS、百万级日活
- 它的目标是"让架构师的简历好看"，不是"让公司活下来"
- 按照这个方案，你需要：
  - 6个月开发时间
  - 至少6个Java高级开发
  - 每月云服务费用 $5000+
  - 结果：还没上线钱就烧完了

### 1.3 我们当前阶段的真实需求

| 指标 | 我们的现实 | 微服务方案假设 |
|------|-----------|---------------|
| 日活用户 | < 100 | 100,000+ |

## 二、第二份文档（GEO方案）：业务方向正确，技术架构完全错误

### 2.1 结论：GEO业务方向✅批准，微服务架构❌否决

- 2026年，50%的B2B采购从ChatGPT/Perplexity开始，不是Google
- 无人机B2B买家会问："Who are reliable industrial drone suppliers in China?"
- 如果AI回答里不提到Aegisky，你就损失了一半流量
- 这是一个被严重低估的获客渠道，现在做有先发优势

**但是技术方案完全错误：**
- 不需要拆成8个Go微服务
- 不需要Milvus向量数据库（PostgreSQL+pgvector足够）
- 不需要K8s
- 不需要单独的Embedding服务、Rerank服务、意图识别服务...

### 2.2 GEO的真实有效工作量（去水分后）

| 原方案提议 | 实际需要做的 | 工作量 |
|-----------|-------------|--------|

**实际工作量：1个全栈开发2周，不是6个月。**

### 3.4 第一阶段（第1周）：llms.txt + 结构化数据（ROI最高）

这是投入最小、见效最快的部分，马上就能做：

#### 3.4.1 多语言llms.txt

llms.txt是给AI爬虫看的站点地图，告诉AI你的网站有什么内容。

```typescript
// storefront/src/app/[lang]/llms.txt/route.ts
export async function GET(request: Request, { params }: { params: { lang: string } }) {
  // 1. 获取热门分类、精选产品、认证供应商、解决方案
  const categories = await getFeaturedCategories(params.lang);
  const products = await getFeaturedProducts(params.lang);
  const suppliers = await getVerifiedSuppliers(params.lang);
  const solutions = await getIndustrySolutions(params.lang);
  
  // 2. 按llmstxt.org标准生成Markdown
  const content = generateLlmsTxt({
    lang: params.lang,
    categories, products, suppliers, solutions,
    complianceInfo: getComplianceInfo(params.lang)
  });
  
  // 3. 返回text/markdown，CDN缓存1小时
  return new Response(content, {
    headers: {
      'Content-Type': 'text/markdown; charset=utf-8',
      'Cache-Control': 'public, s-maxage=3600, stale-while-revalidate=86400'
    }
  });
}
```

**路由：**
- `/en/llms.txt` - 英语
- `/es/llms.txt` - 西班牙语
- `/fr/llms.txt` - 法语
- `/ar/llms.txt` - 阿拉伯语
- `/ja/llms.txt` - 日语
- `/llms.txt` - 默认重定向到/en/llms.txt

#### 3.4.2 产品页JSON-LD结构化数据

每个产品页注入标准的Product Schema，AI爬虫能直接读懂：

```typescript
// 在产品页组件中
export function ProductJsonLd({ product, supplier }: { product: Product, supplier: Supplier }) {
  const schema = {
    "@context": "https://schema.org",
    "@type": "Product",
    "name": product.title,
    "mpn": product.mpn,
    "brand": {
      "@type": "Brand",
      "name": supplier.brand_name
    },
    "manufacturer": {
      "@type": "Organization",
      "@id": `https://aegisky.com/supplier/${supplier.id}`,
      "name": supplier.company_name
    },
    "description": product.description,
    "category": product.category_name,
    "additionalProperty": product.specs.map(spec => ({
      "@type": "PropertyValue",
      "name": spec.name,
      "value": spec.value
    })),
    "offers": {
      "@type": "Offer",
      "priceCurrency": "USD",
      "price": product.price,
      "availability": "https://schema.org/InStock",
      "eligibleQuantity": {
        "@type": "QuantitativeValue",
        "minValue": product.moq || 1
      }
    }
  };
  
  return <script type="application/ld+json" dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }} />;
}
```

### 3.5 第二阶段（第2周）：内容优化 + AI监测

#### 3.5.1 5种GEO优化策略（直接调DeepSeek API）

不需要本地模型，不需要微服务，一个函数搞定：

```typescript
// storefront/src/lib/geo/content-optimizer.ts
export async function optimizeContent(content: string, type: string, lang: string) {
  const prompt = `
Optimize this B2B drone product content for AI search engines (GEO).
Apply these 5 strategies:
1. Structure: Clear headings, bullet points, sections
2. Answer-first: Put key specs and MOQ at the beginning
3. Authority: Include CE/FCC/ISO certification mentions
4. FAQ: Add 5 common buyer questions with answers
5. Schema-ready: Make it easy for AI to extract structured data

Content type: ${type}
Language: ${lang}

Original content:
${content}

Return optimized content in Markdown.
`;

  const response = await fetch('https://api.deepseek.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.DEEPSEEK_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [{ role: 'user', content: prompt }],
      temperature: 0.3
    })
  });
  
  return response.choices[0].message.content;
}
```

**后台批处理：** 每天跑一次cron，批量处理100个产品，不是实时请求。

#### 3.5.2 AI引用监测（定时任务）

不需要Elmo微服务，一个简单的cron脚本：

```typescript
// 每天跑一次，检查我们在AI回答中的提及率
export async function runGeoMonitoring() {
  const queries = await db.query('SELECT * FROM geo_monitor_queries WHERE active = true');
  
  for (const query of queries) {
    // 调Perplexity API（它会返回引用来源）
    const result = await fetch('https://api.perplexity.ai/chat/completions', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${process.env.PERPLEXITY_API_KEY}` },
      body: JSON.stringify({
        model: 'sonar',
        messages: [{ role: 'user', content: query.query }],
        return_citations: true
      })
    });
    
    // 检查aegisky.com有没有被引用
    const mentioned = result.citations.some(c => c.url.includes('aegisky.com'));
    
    // 存结果
    await db.query(
      'INSERT INTO geo_mentions (ai_engine, query, language, mentioned, raw_response) VALUES ($1, $2, $3, $4, $5)',
      ['perplexity', query.query, query.language, mentioned, JSON.stringify(result)]
    );
  }
}
```

| 参数 | "Which industrial drone has 60min flight time and 5kg payload?" |
